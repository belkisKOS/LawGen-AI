# LawGen AI

LawGen AI is a Retrieval-Augmented Generation system for Algerian legal Q&A.

The system is not based on fine-tuning.  
New legal documents are added by ingestion, extraction, chunking, embedding, and indexing into a vector database.

## Main modules

- ingestion: PDF extraction, OCR, chunking, embeddings, indexing
- api: FastAPI backend
- admin-dashboard: document upload and management
- chatbot-frontend: user chatbot interface
- eval: test questions and evaluation
- docs: technical documentation
- data: local development data
